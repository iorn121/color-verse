# 進出色・後退色（色学習）

Issue: https://github.com/iorn121/color-verse/issues/30

確定した方針: Q1=A / Q2=B / Q3=A / Q4=A

## 概要

`/theory` に「進出色・後退色」セクションを足す。同じ大きさの円を中性灰の上で重ね、色相・彩度・明度を動かすと、暖色が手前・寒色が奥に見えやすいことを体感できる。

他の色彩理論トピック（色相環・補色など）は本仕様の範囲外。ルート・ナビ・PWA は変えない。

## 視覚

- 舞台の地は教材用の中性灰 `hsl(0, 0%, 50%)`。ブランド色ではないため `colors.json` には置かない。
- 円は同一直径。横に少し重ね、右の円を手前に塗る。大きさ・ぼかし・コントラストでは奥行きを作らない。
- 初期値は左が暖色（赤）、右が寒色（青）。入れ替えとスライダーで任意の HSL にできる。
- 円の色はユーザー操作の HSL であり、プロダクト用トークンではない。枠・文字・ボタンは既存の `var(--color-*)` を使う。

## 判定（教材用の目安）

`src/lib/advancingReceding.ts`

- 色相の暖寒: 進出色の山を色相 30°（赤橙）に置き、`cos(h - 30°)` で −1（寒）〜 +1（暖）にする。青（約 210°〜240°）は負になる。
- 進出スコア = 暖寒 × 彩度 × 明度ウェイト。明度ウェイトは L=50 で 1、白と黒で 0。
- スコアが閾値を超えると「進出色寄り」「後退色寄り」、それ以外は「差が弱い」。
- 左右のスコア差が小さいときは「奥行きの差は小さい」。

これは知覚の説明用であり、測色の規格値ではない。
