# 比較画面にコントラスト警告を出す

## 背景

Color Verse のロードマップでは、2色の組み合わせから **WCAG 2.x のコントラスト比**を算出し AA / AAA の達成可否を示す機能がコア候補として挙がっている（README「WCAG コントラストチェック（色入力から AA/AAA 判定）」）。ユーザーが文字色と背景色（または任意の前景・背景ペア）を並べて評価する **比較画面** が、その主な入口となる。

現状のリポジトリには `/compare` 相当のルートや専用ページはなく、コントラスト比を算出する `src/lib/` モジュールも未整備である。本仕様は **比較画面におけるコントラスト警告の表示** を定義する。比較画面そのもの（ルート追加・2色入力 UI・プレビュー）が別タスクで未着手の場合は、警告はその画面の「結果パネル」として同時に実装する前提とする。

判定は **WCAG 2.1 の相対輝度とコントラスト比**（通常テキスト向け）に準拠する。画像の Canvas コントラストスライダー（`/image`）や進出色・後退色の教材判定（`/theory`）とは目的が異なり、混同しない。

## 要件

### 機能

1. **対象画面**  
   比較画面でユーザーが指定した **前景色（文字・記号想定）** と **背景色** のペアに対し、リアルタイム（色変更のたび）にコントラスト情報を更新する。

2. **算出**
   - 入力は `#RRGGBB` 形式の HEX を主とし、既存の `src/lib/color.ts`（`hexToRgb` 等）と整合するパース境界を設ける。無効な HEX は警告計算を行わない。
   - **コントラスト比** \( (L1 + 0.05) / (L2 + 0.05) \)（L1 ≥ L2）を WCAG 2.1 の sRGB 相対輝度で算出する。
   - 算出ロジックは UI を持たない **`src/lib/`** に置く（例: `contrast.ts` または `color.ts` への追加）。外部 API は使わない。
   - 返却値は Zod で検証可能な形（例: 比の数値、達成レベル、前景/背景の役割）にまとめ、コンポーネントはその結果だけを表示する。

3. **表示（数値・ラベル）**
   - コントラスト比を **小数第 2 位まで** 表示する（例: `4.52:1`）。
   - 次の **通常テキスト** 基準に対する達成ラベルを表示する。
     - **AA**: 比 ≥ 4.5:1
     - **AAA**: 比 ≥ 7:1
     - 未達時は AA / AAA それぞれ「未達」であることが分かる表示にする（両方未達の場合は AA 未達を主警告とする）。

4. **警告（本仕様の中心）**
   - **AA 未達**（比 &lt; 4.5:1）のとき、比較画面上に **目立つ警告** を出す（アイコンまたはバッジ + 短い説明文）。成功時（AA 以上）は警告ブロックを出さない、または非警告の状態表示のみとする。
   - **AAA 未達かつ AA 達成**（4.5 ≤ 比 &lt; 7）のときは **警告ではなく情報**（ヒント）として区別してよい（例: 「AA は満たしていますが AAA には届きません」）。AA 未達と同じ強度の警告 UI にしない。
   - 前景・背景の **入れ替え** 操作がある場合、警告は入れ替え後のペアで再計算する。

5. **プレビューとの整合**  
   比較画面にサンプル文言のプレビュー（前景 on 背景）がある場合、警告はそのプレビューと **同じ色ペア** を参照する。プレビューが無い最小構成でも、2色スウォッチと警告は一致させる。

6. **i18n**  
   警告・ラベル・比の説明・無効入力時のメッセージは **`public/locales/ja/common.json` と `en/common.json`** にキーを追加する（名前空間 `common`、例: `pages.compare.contrast.*`）。コンポーネントに長文を直書きしない。

7. **UI / 色トークン**
   - 枠・文字・警告コンテナは既存の **`var(--color-*)`** を用いる。
   - 新規のセマンティック色（警告面・成功面など）が必要なら、実装前に **`src/theme/colors.json`**（未作成なら新規）へトークン追加し、`index.css` と整合させる。警告用 Hex の UI 直書きは増やさない。
   - **PWA**: 本機能のため `vite.config.ts` の manifest や Service Worker 設定は変更しない。

8. **アクセシビリティ（警告 UI 自体）**
   - AA 未達警告は `role="alert"` または同等のライブリージョンで、スクリーンリーダーが状態変化を読めるようにする。
   - 警告の伝達は **色だけに依存しない**（文言・アイコン等を併用）。

### 想定配置（実装時の参照）

| 領域                                 | 役割                                                       |
| ------------------------------------ | ---------------------------------------------------------- |
| `src/pages/`                         | 比較画面（例: `ComparePage.tsx`）                          |
| `src/components/color/`              | 2色入力・プレビュー・警告パネル                            |
| `src/lib/`                           | 相対輝度・コントラスト比・達成判定                         |
| `src/router.tsx`                     | 比較画面ルート（例: `/compare`）— 比較画面新設タスクと一体 |
| `public/locales/{ja,en}/common.json` | 文言                                                       |

## 受け入れ条件

1. 有効な前景 `#000000`・背景 `#FFFFFF` のペアで、コントラスト比が **21:1**（表示上 21.00:1 前後）となり、**AA・AAA とも未警告（または成功表示）** である。
2. 有効な前景 `#777777`・背景 `#FFFFFF` のペアで、比が **4.5:1 未満** となり、**AA 未達の警告** が表示され、警告文が i18n キー経由で ja / en 切替できる。
3. 比が **4.5:1 以上 7:1 未満** の既知ペア（例: 前景 `#767676`・背景 `#FFFFFF`、比約 4.54:1）で、**AA 達成**かつ **AAA 未達** が区別でき、AAA 不足が AA 未達警告と同強度の「エラー警告」にならない。
4. 無効な HEX（空文字・ `#GGG` 等）では警告を出さず、**無効入力用のメッセージ** を表示する（計算結果を表示しない）。
5. 前景と背景を入れ替えたとき、比は **不変**（数学的対称）で、達成ラベル・警告状態が入れ替え後の色役割と一致する。
6. `npm run typecheck && npm run build` が通る（実装 PR 時）。

## 対象外

- **大文字** WCAG 基準（18pt 以上 / 14pt bold 相当の **3:1**）の自動判定 UI（将来拡張とする。初期は通常テキスト 4.5:1 / 7:1 のみ）。
- **APCA**、CMYK、印刷 ICC、ガンマ補正済み画像からの自動前景/背景抽出。
- コントラスト不足に対する **自動配色修正・代替色提案**（README アイデアの「CVD 代替配色」等は別 spec）。
- 色覚特性シミュレーション後のコントラスト再評価（`/camera-cvd` 連携）。
- 比較画面以外（色詳細・図鑑・パレット履歴比較など）への警告の横展開。
- コントラスト履歴の IndexedDB 保存、共有 URL、エクスポート。
- `vite.config.ts` / `index.html` の PWA 注入まわりの変更。
- ホーム画面へのリンク追加・グローバルナビ改修（別 UX タスクとする場合は本 spec では必須にしない）。

## テスト

### 手動（ブラウザ）

| #   | 操作                                      | 期待結果                                                               |
| --- | ----------------------------------------- | ---------------------------------------------------------------------- |
| T1  | 前景 `#000000`、背景 `#FFFFFF`            | 比 ≈ 21:1、AA/AAA 達成、AA 未達警告なし                                |
| T2  | 前景 `#767676`、背景 `#FFFFFF`            | 比 &lt; 4.5:1、AA 未達警告表示、`role="alert"` 等で読み上げ可能        |
| T3  | AA 達成・AAA 未達の既知ペア               | AA 表示は達成、AAA は未達、AAA は情報扱い（T2 と同種の強警告にしない） |
| T4  | 前景 `#FFFFFF`、背景 `#000000`（T1 の逆） | T1 と同じ比・同じ達成判定                                              |
| T5  | 入れ替えボタン（あれば）                  | 比は不変、プレビューの文字/地色が入れ替わる                            |
| T6  | 無効 HEX を入力                           | 警告・比が消え、無効メッセージ表示                                     |
| T7  | 言語を en に切替                          | 警告・ラベルが英語辞書から表示される                                   |

### 単体（推奨・実装時）

- `src/lib/` のコントラスト関数に対し、WCAG 公式例に近い固定ペア（黒/白、既知グレー/白）で **比の許容誤差**（例: ±0.01）テスト。
- 無効 HEX で `null` または判別可能なエラー型を返すテスト。

## 承認

2026-10-04 に、この仕様のまま実装することが承認された。AA（4.5:1）未達だけを強い警告とし、AAA（7:1）未達は情報表示とする。比較画面（`/compare` と 2色入力）も実装範囲に含める。

### 回帰

- `/image` の Canvas コントラスト、`/theory` の進出/後退判定が本変更で変わらないこと。
- 実装後: `npm run typecheck && npm run build`、必要なら `npm run check`。
