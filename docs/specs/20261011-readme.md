# README 末尾に動作確認用の一文を追加する

Slug: readme-verification-sentence

## 背景

Color Verse の `README.md` はセットアップ手順（`npm install` / `npm run dev` 等）を既に記載しているが、リポジトリを clone した直後や README だけを参照する場面（GitHub 上の表示、オンボーディング、ドキュメント更新の差分確認）で、**最短の動作確認手順を末尾で一目できる**ようにしたい。

README 本体の再構成（バックログ移管・アイデア100の整理など）は別タスクとして README「改善点バックログ」に残っている。本仕様は **末尾への1文追加のみ** に限定し、既存セクションの並べ替え・削除・大幅な書き換えは行わない。

## 要件

1. **変更対象ファイル**  
   リポジトリルートの **`README.md` のみ** を編集する。アプリケーションコード、設定（`vite.config.ts` 等）、依存関係（`package.json`）、i18n 辞書、PWA 関連ファイルは変更しない。

2. **追加位置**  
   `README.md` の **ファイル末尾** に、**1文だけ** を追加する。
   - 既存の最終セクション（「改善点バックログ」）の内容はそのまま残す。
   - 追加文は、バックログのチェックリスト等の **後**、ファイルの **最終行付近** に置く（必要ならその直前に区切り用の空行を1行入れてよい）。

3. **文の内容**
   - **日本語** で書く（README 全体の言語に合わせる）。
   - **動作確認用** であることが読み手に伝わること（例: 開発サーバー起動とブラウザ表示の確認）。
   - 既存「セットアップ」節と矛盾しないこと。新しいコマンドや別ポートを invent せず、README に既に記載の **`npm run dev`** と **`http://localhost:5173`**（または README が指定する開発 URL）を参照する。
   - **1文** に収める（句点1つで終わる短文。箇条書き・コードブロック・見出しの新設はしない）。
   - 実装時の文案例（そのまま使っても、同等の意味に言い換えてもよい）:  
     「動作確認: リポジトリルートで `npm run dev` を実行し、ブラウザで http://localhost:5173 が表示されればセットアップは問題ありません。」

4. **Markdown 体裁**
   - インラインコード（バッククォート）でコマンド・URL を示してよい（README 既存表記に合わせる）。
   - 絵文字の新規追加は必須としない。
   - MIT ライセンス表記や既存の `---` 区切りの意味を変えない（ライセンス節の位置は動かさない）。

5. **スコープ外の README 変更**  
   本タスクでは、アイデア100・バックログ・ロードマップ節の編集、セットアップ節の重複コピー、英語版 README の新設は行わない。

## 受け入れ条件

1. `README.md` の末尾に、上記要件を満たす **動作確認用の日本語1文** が存在する。
2. 追加以外の README 本文について、意図しない大規模な削除・並べ替えがない（末尾1文＋必要なら空行1行程度の差分）。
3. `README.md` 以外のファイルに変更がない（本仕様の実装 PR 時）。
4. 追加文が README 既載の開発手順（`npm run dev`、ローカル URL）と整合している。

## 対象外

- README の再構成（「今後の対応策」「改善点バックログ」の移管・短縮）。
- `docs/backlog/` への機能アイデア100の分割。
- GitHub Pages の URL 説明、CI 手順、Dependabot 等の README 追記（別 spec / バックログ項目）。
- 英語 README、`public/locales/` の更新。
- 動作確認文をアプリ UI や PWA manifest に表示する機能。
- 自動テストや CI で README 末尾を検証するジョブの追加（必要なら別タスク）。

## テスト

### 手動

| #   | 操作                                                                       | 期待結果                                                                      |
| --- | -------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| T1  | GitHub またはエディタで `README.md` を開き、ファイル末尾を表示する         | 動作確認用の1文が最下部付近に見える                                           |
| T2  | 追加文に記載されたコマンドを README「セットアップ」と照合する              | `npm run dev` 等、セットアップ節と同じコマンド・URL である                    |
| T3  | リポジトリルートで `npm install`（未実施時）の後、`npm run dev` を実行する | ブラウザで README が示す開発 URL のトップが表示される（環境が整っている場合） |
| T4  | `git diff README.md` を確認する                                            | 末尾追加（と空行）以外に README の意図しない変更がない                        |

### 回帰

- 本変更はドキュメントのみのため、`npm run typecheck && npm run build` は **必須の受け入れ条件には含めない**（コード未変更のため）。実装者は任意で実行してよい。
